## 一、页面结构图（全站路由与导航关系）

```
房价雷达（Astro 静态站，移动端优先，390px 基准）
│
├─ 全局壳层 AppShell
│   ├─ 顶栏（移动端）：品牌标识 + 城市徽标 CityScopeBadge + 通知入口 + 账户入口
│   ├─ 顶栏（≥768px 桌面）：品牌 + 顶部导航（复用同一信息架构）+ 内容区最大 1200px 居中
│   └─ 底部导航 MobileBottomNav（固定定位 + env(safe-area-inset-bottom)，主内容预留其高度）
│       5 个 Tab：首页 / 区域 / 小区 / 监控 / 事件
│
├─ 1. /                          首页（当前城市市场摘要）
│      ├─ GlobalSearch（全局搜索，含城市切换/添加城市入口）
│      ├─ 今日数据状态卡（DataFreshnessBadge + SampleCountLabel）
│      ├─ 今日与我有关事件（EventTimelineItem）────→ /events
│      ├─ 我的重点监控（WatchItemCard + TargetPriceProgress）──→ /watch
│      ├─ 区域市场变化（PriceMetricCard + PriceChangeBadge + 趋势图）──→ /regions
│      ├─ 最近更新的小区（CommunityCard）────→ /community?id=
│      └─ 数据说明入口（SourceAttribution 汇总）──→ /account#privacy
│
├─ 2. /regions                   区域（区县/板块导航与市场概览）
│      ├─ 城市切换/添加入口（城市选择器：337 目录城市，可检索；状态=可申请/未覆盖）
│      ├─ 区县横向筛选（query 参数 ?district=）
│      ├─ 价格口径切换（挂牌参考 / 实际成交，client 切换）
│      ├─ 区域价格卡 + 趋势图（周期 7/30/90/180 日/1 年）
│      └─ 区县列表 ──→ /region?id=
│
├─ 3. /region?id=                区县详情（查询参数指定对象）
│      ├─ 区县名 + 行政路径 + 数据质量标签
│      ├─ 分栏：新房 / 二手房 / 成交（client 切换）
│      ├─ 指标：挂牌中位价、均价、样本量、成交量/成交额、价格指数
│      ├─ 时间范围切换 + 趋势图（标注指标类型、来源、统计日期）
│      ├─ 同级区县比较（同口径同周期）
│      └─ 加入监控（游客 → Permission 注册引导）
│
├─ 4. /communities               小区搜索
│      ├─ 搜索框置顶（输入联想，同名消歧提示）
│      ├─ 区县/板块筛选 + 排序（价格/涨跌/样本数，query 参数）
│      └─ 小区结果卡 CommunityCard ──→ /community?id=
│
├─ 5. /community?id=             小区详情（查询参数指定对象）
│      ├─ 小区名 + 行政区/板块 + 数据覆盖状态标签
│      ├─ 价格口径切换（挂牌参考 / 实际成交 / 官方指数）
│      ├─ 主卡：挂牌中位价（PriceMetricCard：口径+日期+样本量+状态）
│      ├─ 均价 / P25 / P75 / 有效样本量（SampleCountLabel，低样本降级强调）
│      ├─ 趋势图（30/90/180 日，内联 SVG）
│      ├─ 数据来源明细（SourceAttribution）
│      └─ 操作：设定目标价 → /rules ；加入监控（游客 → Permission 引导）
│
├─ 6. /watch/add                 添加监控（分步表单 5 步）
│      选择对象 → 价格口径 → 目标条件 → 通知方式 → 确认
│      每步可前进/后退；必填校验与错误提示；确认页复述数据口径
│
├─ 7. /watch                     我的监控
│      ├─ 今日变化摘要卡
│      ├─ 筛选 Tab（全部/区域/小区/房源/已触发，query 参数）
│      ├─ WatchItemCard：最新值/目标值/价差/日期/样本/质量/最近事件
│      │    操作：暂停·恢复（本地状态）、编辑目标价 → /rules、删除（ConfirmDialog）
│      └─ 空态 EmptyState → 引导去 /watch/add
│
├─ 8. /rules                     规则编辑
│      ├─ 现有规则列表（目标价、跌幅阈值、通知渠道，可停用）
│      └─ 规则表单（校验：目标价>0、跌幅 0–100%）→ 保存（本地状态）/ 暂未开放项标注
│
├─ 9. /events                    事件中心
│      ├─ 筛选（全部/未读/已读，query 参数）
│      ├─ 时间线 EventTimelineItem：级别、对象、价差、数据日期、来源
│      └─ 操作：标记已读/未读（本地状态）、查看证据（展开明细）
│
├─ 10. /briefing                 每日简报
│      ├─ 日期选择（今日/昨日）
│      ├─ LoadingSkeleton（生成中）→ 简报正文（事件摘要 + 数据口径）
│      └─ 空态（无简报日）EmptyState
│
├─ 11. /login                    登录（邮箱 → 验证码两步）
│      ├─ 第一步：邮箱输入（格式校验）→ 发送验证码
│      ├─ 第二步：6 位验证码 + 60s 倒计时 + 重发（限流提示）
│      └─ 隐私说明 + 错误状态（错误码演示、限流演示）
│
├─ 12. /account                  账户与隐私说明
│      ├─ 邮箱、通知渠道开关（站内/邮件；浏览器通知拒绝降级说明）
│      ├─ 会话退出、数据导出、删除关注、注销账号（ConfirmDialog / 暂未开放标注）
│      └─ 隐私政策、用户协议、游客本地收藏说明（仅存当前设备）
│
└─ 13. /admin                    管理员总览（1440px 桌面布局；≤768px 降级为单栏）
       ├─ 左侧深色导航（总览 + 9 个子模块入口，未建路由者标"暂未开放"）
       ├─ 顶部状态条：城市范围切换 / 采集运行状态 / 管理员账户
       ├─ 指标卡（4 张：覆盖率、延迟源、待审对象、今日事件）
       ├─ AdminDataTable：对象目录数据表（搜索、状态筛选、行点击）
       └─ 右侧详情抽屉（Drawer）：选中行详情 + 审批/停用操作（ConfirmDialog）

导航关系要点：
- 底部 5 Tab 与 PRD 2.1 信息架构一致（"我的"能力并入"监控"Tab，账户入口在顶栏）。
- 桌面端（≥768px）隐藏底部导航，改为顶部导航，功能信息架构不变。
- 所有跨页跳转使用真实 `<a href>`；同页筛选/切换使用 query 参数或本地 JS 状态，保证静态构建可用。
- 管理后台为独立壳层（不显示用户端底部导航）。

## 三、Design Tokens 汇总表

> 完整可运行定义见 `apps/web/src/styles/tokens.css`（本设计稿附件，随本设计稿一同先行提交）。

### 3.1 颜色（PRD §2.2A 色值表，原样执行）

| Token | 色值 | 用途 |
|---|---|---|
| `--color-brand-900` | `#14253D` | 品牌深海军蓝、主标题、顶部重点区 |
| `--color-brand-700` | `#1E3A5F` | 深色导航、重点文字 |
| `--color-primary` | `#3277E6` | 主按钮、当前选中、交互链接 |
| `--color-primary-soft` | `#EAF2FF` | 选中背景、信息卡片 |
| `--color-bg` | `#F5F7FA` | 页面背景 |
| `--color-surface` | `#FFFFFF` | 卡片/弹层背景 |
| `--color-border` | `#E5EAF1` | 分割线、卡片边框 |
| `--color-text` | `#172B4D` | 主文字 |
| `--color-muted` | `#6B778C` | 次级信息、数据说明 |
| `--color-down` | `#15966A` | 房价下降/低于目标；必须同时显示"下降"文字和箭头 |
| `--color-up` | `#D84A4A` | 房价上涨/高于目标；必须同时显示"上涨"文字和箭头 |
| `--color-warning` | `#D98B20` | 数据延迟、样本不足、待核验 |
| `--color-danger` | `#C83D4D` | 严重错误、权限/采集失败 |
| `--color-neutral` | `#7B8798` | 暂无数据、未覆盖、停用 |

规则：颜色不得作为唯一编码；涨跌 = 箭头 + 文字 + 数值三重编码；禁止用绿色"正常"掩盖数据延迟。

### 3.2 字体

| Token | 值 | 说明 |
|---|---|---|
| `--font-sans` | 系统中文字体栈（-apple-system / PingFang SC / Microsoft YaHei …） | 无外部字体请求 |
| `--font-numeric` | sans + `font-variant-numeric: tabular-nums`（工具类 `.num`） | 所有价格/涨跌数字等宽 |
| `--text-xs`…`--text-2xl` | 12 / 13 / 15 / 17 / 20 / 24 / 32px | 说明→正文→标题→主指标→首要价格 |
| `--weight-*` | 400 / 500 / 600 / 700 | 层级区分靠字重不靠颜色 |
| `--line-tight` / `--line-normal` | 1.25 / 1.5 | 标题紧、正文松 |

### 3.3 间距（8px grid）

| Token | 值 | 用途 |
|---|---|---|
| `--space-0-5` | 4px | 图标与文字微对齐 |
| `--space-1` | 8px | 元素内小间隔 |
| `--space-1-5` | 12px | 卡片内分组 |
| `--space-2` | 16px | 页面左右边距 / 卡片 padding |
| `--space-3` | 24px | 模块之间 |
| `--space-4` | 32px | 页面大分节 |

### 3.4 圆角与阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius-card` / `--radius-card-sm` | 16px / 14px | 卡片圆角（PRD 要求 14–16px） |
| `--radius-input` | 10px | 输入框 |
| `--radius-pill` | 999px | 徽标/胶囊按钮 |
| `--shadow-card` / `--shadow-raised` / `--shadow-dialog` | 3 档克制阴影 | 卡片 / 悬浮 / 弹层 |

### 3.5 尺寸与断点

| Token | 值 | 用途 |
|---|---|---|
| `--viewport-base` | 390px | 主设计基准视口 |
| `--page-gutter` | 16px | 手机页面左右边距 |
| `--hit-target` | 44px | 交互区最小高度 |
| `--input-height` | 48px | 表单输入高度 |
| `--bottom-nav-height` + `--safe-bottom` | 56px + `env(safe-area-inset-bottom)` | 底部导航与安全区 |
| `--content-max` | 1200px | 桌面端内容最大宽度 |
| 断点登记 | 360 / 375 / 390 / 430 / 768 / 1440px | 360–430 手机适配；768 顶部导航切换；1440 后台基准 |
