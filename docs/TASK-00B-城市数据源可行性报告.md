## 2. 城市目录与数据覆盖的分离（V1.2 架构决策落地）

- 城市目录（`catalog_status`）= 用户可搜索/可添加的城市，**与房价数据无关**；337 城全部开放选择。
- 数据覆盖（`status`）= active/limited/requestable/suspended；**当前 337 城全部为 `requestable`**——无任何城市宣称可自动监控，页面须显示"当前未覆盖"并允许提交覆盖申请。
- 无 `PILOT_CITY_CODE`，无全站唯一城市；青岛仅为核验样本，核验完成后是否将其 `status` 升级为 active/limited 由数据源核验结果决定。
- 用户输入城市不在目录时走"城市目录补录申请"流程（管理员核实国标代码后新增）。

### 3.2 政府开放数据要点

- **国家统计局 70 城指数**：每月 15 日前后发布（最新 2026-09 期于 2026-10-19 发布）；新建住宅用网签数据、二手住宅为重点/典型调查；服务条款明确允许下载使用、转载注明出处——可直接用于宏观趋势，**不是小区成交单价**。
- **深圳**（PRD §5.5 指名候选，已实测核验）：`二手房成交信息（按日统计）`（数据集 29200/01903513）真实、按日更新（最近 2026-11-10）、无条件开放、条款允许衍生使用；**但字段只有日期/套数/面积/用途/所属区，无单价、无小区**——PRD "不得宣称其具备小区级成交价格字段"的警告成立。
- **杭州**：开放平台有"住宅销售价格指数"（更新至 2026-11-09）与"商品住房一房一价"（2010 至今备案价，可到房屋级）；后者为一手房网签备案口径，**不等于二手房成交价**，且有条件数据需签利用协议——待许可条款确认（`pending_review`）。
- **青岛**：见 §4.1（核验结果另行填入）。

### 4.3 价格口径与样本量说明

- 当前无任何 `approved` 级别的小区级价格数据源 → **10–20 个小区的"真实价格样本"核验被数据源授权阻塞**，不伪造价格。
- 已完成的是**目录层核验**（名称/区归属/消歧/来源）；价格层核验待以下任一条件满足后补做：① 贝壳书面授权；② 杭州一房一价许可确认（一手备案价口径）；③ 负责人批准的其他合规来源；④ 用户手工录入闭环在真实小区上跑通（记为 `manual_verified` 口径）。

## 6. 缺口清单（按优先级）

1. **小区级价格源缺失**——V1 监控核心指标（小区中位价、挂牌样本）暂无 `approved` 来源；这是把城市 `status` 升为 active 的**硬阻塞**。
2. 贝壳开放平台商务授权未发起（需负责人以公司/个人身份接洽）。
3. 杭州一房一价、上海有条件开放数据的许可条款/协议门槛未确认。
4. 各区政府开放平台覆盖不均，无法承诺逐城逐区覆盖。
5. 核验样本城市（青岛）若无合格价格源，其 `status` 保持 `requestable`。
